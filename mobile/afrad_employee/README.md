# Afrad Employee (Flutter)

Employee attendance client for the Afrad token API (`/api/v1`): sign in with the company address, check in and out (location sent when the company policy asks), breaks, recent days. Arabic (RTL) and English.

- `flutter pub get && flutter test && flutter analyze`
- Android APK / iOS build need the Android SDK or Xcode. Store release is a separate decision and is not part of this repo.
- The company's attendance policy must have mobile check-in enabled and the employee must be linked to a login.
